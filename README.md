# Гараж №1 — учёт клиентов и записей

Небольшое веб-приложение для автосервиса:

- **База клиентов** — имя, телефон, марка/модель авто, гос. номер, заметки. Поиск по всем полям.
- **Расписание на неделю** — записи по дням (Пн–Сб, рабочая неделя без воскресенья), переключение недель, статусы (запланировано / в работе / готово / отменено).
- **Разовые визиты** — запись можно создать вообще без привязки к клиенту из базы: просто вписать имя/телефон/авто прямо в форме записи. Такие данные хранятся только в самой записи и в базу клиентов не попадают.
- Данные общие для всех, кто открывает приложение — то есть это уже «общий доступ в кабинет» для сотрудников на одной сети/сервере.

## Стек

- **Backend:** Node.js (встроенный `http`, без Express) + встроенный `node:sqlite` — **нет ни одной внешней зависимости**, `npm install` не нужен.
- **Frontend:** обычные HTML/CSS/JS, без сборщиков.
- **Требование:** Node.js **22.5+** (нужен для `node:sqlite`). Проверить версию: `node --version`.

## Запуск локально

```bash
node server.js
```

Откройте http://localhost:3000

При первом запуске автоматически создастся файл `autoservice.db` (SQLite) со всеми таблицами — ничего дополнительно настраивать не нужно.

Порт можно поменять переменной окружения:

```bash
PORT=8080 node server.js
```

## API

| Метод | Путь                                   | Описание                          |
|-------|-----------------------------------------|------------------------------------|
| GET   | `/api/clients`                          | Список клиентов                    |
| POST  | `/api/clients`                          | Создать клиента                    |
| PUT   | `/api/clients/:id`                      | Обновить клиента                   |
| DELETE| `/api/clients/:id`                      | Удалить клиента (и его записи)     |
| GET   | `/api/appointments?start=&end=`         | Записи в диапазоне дат (YYYY-MM-DD)|
| POST  | `/api/appointments`                     | Создать запись                     |
| PUT   | `/api/appointments/:id`                 | Обновить запись                    |
| DELETE| `/api/appointments/:id`                 | Удалить запись                     |

## Общий доступ для сотрудников

Сейчас приложение не требует логина — кто открыл ссылку на сервер, тот и видит/редактирует данные. Для реального использования в цеху этого обычно достаточно, если сервер доступен только в локальной сети автосервиса или через приватный туннель.

Если понадобится:
- **Публичный доступ из интернета** — задеплойте на любой хостинг с поддержкой Node.js (Render, Railway, Fly.io, VPS) и держите порт открытым.
- **Логин/пароль для сотрудников** — можно добавить простую базовую аутентификацию отдельным следующим шагом.
