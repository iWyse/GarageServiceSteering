# Правила работы с репозиторием

- **История изменений ведётся во вкладке «Версия».** Каждое изменение сайта вносится в
  `public/changelog.json` в том же коммите: запись текущей даты (новые сверху), категории
  `added` / `improved` / `fixed` / `removed`, формулировки — для пользователя, а не про код.
  Подробности — в README, раздел «Вкладка «Версия»».
- Файл `autoservice.db` и `.env` не коммитятся (они в `.gitignore`); `autoservice.db` — рабочая база
  клиентов, её не удалять и не перезаписывать. Для демо — `npm run seed:demo` на пустой базе.
- Минимальный размер шрифта на сайте — 14px.
